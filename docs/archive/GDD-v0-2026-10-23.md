# **Hermes Express: Game Design Document**
## **1. Game Overview**
*Apa game ini, untuk siapa, dan kenapa ada.*
### **1.1 Concept**
**A survival delivery game where your cargo changes how you drive.**
Hermes, dewa pembawa pesan yang diturun pangkatkan, kehilangan sandal bersayapnya dan kini mengantar paket para dewa dengan van tua di Mount Olympus versi modern. Paket biasa aman, paket dewa memberi blessing yang hilang begitu diantar, dan paket selundupan bisa berbuah untung atau jebakan. Roguelike, komedi, arcade. Mac.
### **1.2 Summary & Hook**
Target MVP : satu run ±15 menit (7 hari in-game, ±2 menit per hari)
  - **Konsep:** Hermes menebus diri sebagai kurir Hermes Express. Setiap hari ada quota, gagal sekali = run selesai, ulang dari Day 1.
  - Core Loop: pagi di HQ, cari paket, antar, hindari hazard, senja, pulang dan laporan (rinci di bagian 3).
  - Hook Awal**:** paket Zeus memberi lightning immunity selama dibawa. Begitu diantar, blessing ikut pergi, dan pemain harus pulang melewati badai tanpa perlindungan. *The blessing belonged to the package, not you.*
## **2. Design Pillars**
*Beberapa prinsip yang menyelesaikan debat desain.*
1.  **Push your luck:** setiap hari pemain menimbang antara pulang tepat waktu atau mengambil satu paket lagi. mengambil paket illegal yang berpotensi scam tapi reward besar.
2.  **Simple to play:** 4 tombol drive + E untuk ambil dan antar.
3.  **Whimsical & comedic:** Muncul dari sistem blessing dan paket illegal yg scam. style low poly kartunis juga amplified it.
4.  ***Bro thinks he's smart :*** Pemain merasa jenius saat memilih paket dan rute, sampai rencananya berantakan di jalan pulang.
## **3. Core Gameplay Loop**
*Siklus aksi pemain yang berulang, dari pagi sampai akhir hari.*
1.  **Pagi di HQ:** pilih kartu upgrade (lihat 4.5), lalu berangkat. HQ hanya untuk spawn dan upgrade.
2.  **Cari paket:** paket muncul acak di map (model Crazy Taxi). Berhenti di penanda + tekan E untuk mengambil.
3.  **Antar:** berhenti di tujuan + tekan E. Uang masuk saat paket diantar.
4.  **Hindari hazard:** petir di sekitar Zeus, Minotaur di open area, gelap di malam hari. Setiap tabrakan menambah damage.
5.  **Senja:** peringatan pulang. Kembali ke HQ untuk mengakhiri hari, atau overtime dan diburu badai.
6.  **Akhir hari di HQ:** laporan profit, damage cost dan dibandingkan dengan quota hari itu.
## **4. Game Mechanics**
*Aturan dan sistem yang disentuh pemain.*
### **4.1 Day Cycle**
Satu hari ±2 menit nyata. Jam di bawah adalah titik awal tuning.

| Jam (in-game) | Yang terjadi |
| :- | :- |
| 06:00 | Berangkat dari HQ. Paket mulai muncul di map |
| Siang | Ambil dan antar paket sebanyak mungkin. Uang masuk saat diantar |
| 18:00 | Senja: peringatan "Pulang ke HQ!". Jalan mulai gelap, hazard meningkat |
| 20:00 | Badai Zeus mulai memburu: petir menyasar posisi mobil (tetap dengan telegraph), damage terus bertambah sampai pemain pulang |
| Di HQ | Laporan profit → toko upgrade → hari berikutnya |

### **4.2 End-of-Day Report**

| Baris | Contoh |
| :- | :- |
| Income | $1000 |
| Damage loss (repair) | −$300 |
| Undelivered offering | −10% per paket yang tidak terantar |
| **Profit** | **$700** |

Profit ≥ quota hari itu → lanjut. Profit < quota → game over, ulang dari Day 1.
### **4.3 Package System**

| **Kategori** | **Risiko → reward** | **Slot** | **Cara kerja** |
| :- | :- | :- | :- |
| **Safe** (biasa) | Rendah → rendah | 1 | Muncul acak di map, tanpa efek |
| **Skill** (dewa) | Tinggi → tinggi | 2 | Zeus: kebal petir + cahaya selama dibawa; blessing hilang saat diantar. Risikonya datang setelah antar, jadi ditentukan skill menyetir. Memakan 2 slot, jadi membawanya berarti mengorbankan paket lain |
| **Chance**    (selundupan) | Tinggi → tinggi | 1 | Ditawarkan di pinggir jalan, terpisah dari paket biasa. Persentase scam terlihat(misal 5% atau 20%); bayaran naik sebanding. Saat diantar: legit = uang, scam = damage |

### **4.4 Damage System**
  - Tidak ada HP, mobil tidak bisa mati. Satu-satunya kondisi kalah: gagal quota.
  - Tabrakan, hazard, dan scam menambah damage, terlihat lewat 3 state mobil (mulus → penyok → rusak berat). 
  - Angkanya baru muncul di laporan akhir hari sebagai kejutan, dirinci per kejadian, supaya pemain belajar seberapa mahal kecerobohannya.
### **4.5 Upgrade System**
Upgrade bukan daftar tetap yang dibeli satu per satu, tapi pilihan yang berbeda tiap run. Tujuannya: tiap run punya build sendiri, dan pemain memilih dengan menimbang untung dan rugi (pillar Push your luck).
  - Setelah hari yang lolos quota, Bengkel menawarkan 3 kartu. Pemain memilih 1 secara gratis.
  - Reroll: ganti ketiga kartu dengan kas bengkel; harganya naik tiap reroll pada tawaran yang sama.
  - Kartu tambahan: pemain boleh mengambil 1 kartu lagi dari tawaran itu dengan kas bengkel.
  - Kas bengkel = profit di atas quota (tidak berubah). Surplus besar berarti lebih banyak pilihan.
  - Tiap kartu hanya muncul sekali per run. Gagal quota berarti semua upgrade hilang.
  - Dua jenis kartu: Bersih (kuat sedang, tanpa rugi) dan Gamble (lebih kuat, ada harga). Tiap slot tawaran punya peluang menjadi Gamble; minimal 1 kartu per tawaran adalah Bersih.
Ditunda (visi, bukan MVP): rarity bertingkat (common, rare, epic), kartu yang naik level, dan tag dengan bonus set. Pool awal sekitar 16 kartu.
Contoh kartu (angka awal, dituning lewat playtest):

| **Tema** | **Bersih** | **Gamble** |
| :- | :- | :- |
| Cargo | Rak Atap: capacity 3 → 4 | Muatan Berlebih: capacity 3 → 5, speed −10% |
| Speed | Mesin: speed +20% | Turbo: speed +35%, grip −20% |
| Petir | Penangkal: kebal petir 1× per hari | Penangkal Besar: kebal 2× per hari, badai datang 1 jam lebih awal |
| Bumper | Bumper Empuk: biaya repair −10% | Bumper Baja: biaya repair −40%, akselerasi −10% |

## **5. Progression & Run Structure**
*Alur satu run dan urutan pemain mempelajari tiap sistem.*
### **5.1 Run Structure**
Olympus adalah map pertama dan satu-satunya di MVP. Satu run = 7 hari, ±15 menit. Run pertama di-script sebagai tutorial, run berikutnya memakai spawn dan hazard acak. Urutan pengenalan di bawah adalah usulan.
Region lain dan meta-progression (unlock cerita, area, variasi karakter) adalah visi jangka panjang, bukan bagian dari build MVP. Run 7 hari di Olympus harus terasa selesai dengan klimaksnya sendiri.
### **5.2 Day-by-Day Progression**

| Fase | Isi | Yang diajarkan |
| :- | :- | :- |
| Intro | Hermes dicabut status dewanya dan sandal bersayapnya disita. Ia terdampar di kaki Olympus dengan van tua dan harus menebus diri lewat Hermes Express | Motivasi + quota |
| Day 1 | Driving dasar + paket Zeus (di-script). Blessing hilang, pulang ke HQ lewat badai. Quota rendah | Hook |
| Day 2 | Paket biasa muncul acak di map | Model Crazy Taxi, capacity |
| Day 3 | Paket selundupan pertama | Taruhan scam |
| Day 4–7 | Semua sistem aktif, quota naik sedikit setiap hari | Push your luck penuh |
| Ending | Lolos Day 7 = selangkah lebih dekat ke status dewa + teaser region berikutnya. Gagal = Hermes tetap manusia biasa, ulang dari Day 1 | Roguelike |

## **6. Story & Narrative**
*Cerita, protagonis, dan bagaimana narasi menopang sistem.*
### **6.1 Premise**
**Premis:** dulu Hermes adalah satu-satunya messenger Zeus dan Hera. Suatu hari ia salah kirim: paket untuk "kenalan"Zeus yang lain jatuh ke tangan yang salah. Zeus dan Hera bertengkar, Hermes dicabut status dewanya dan sandal bersayapnya disita, lalu dihukum menjadi kurir seluruh dewa tanpa batas waktu. Sejak itu Hera punya messenger sendiri, Iris.
### **6.2 Protagonist: Hermes**
  - **Motivasi:** mengembalikan kekuatan dan status dewanya lewat Hermes Express yang baru ia dirikan.
  - **Sifat:** jujur, pekerja keras, cerdik, humoris.
  - **Flaw:** terdesak waktu dan keadaan, jadi rela mengambil jalan grey area.
  - **Arc:** sejak awal ragu akan tempatnya di antara para dewa; setiap hari adalah pembuktian.
### **6.3 Narrative–System Alignment**

| Sistem | Alasan naratif |
| :- | :- |
| Quota harian | Penebusan: setiap hari adalah evaluasi dari para dewa |
| Menyetir | Sandal bersayap disita; dewa tercepat di Olympus kini naik van tua |
| Paket selundupan, overtime | Hermes terdesak dan rela masuk grey area |
| Badai pemburu | Zeus tidak suka kurirnya berkeliaran setelah jam kerja |
| Gagal quota | Hermes tetap jadi manusia biasa |

## **7. World & Level Design**
*Di mana game berlangsung dan bagaimana map membentuk permainan.*
  - Setting: Mount Olympus versi modern (urban fantasy). Olympus adalah map pertama dan satu-satunya di MVP.
  - HQ: titik spawn dan upgrade; setiap hari berakhir di sini.
  - Zona Zeus: petir dengan telegraph sekitar 1 detik. Tujuan paket Zeus adalah electrical plant, sehingga jalan pulang melewati ladang petir.
  - Open area: Minotaur menyeruduk lurus.
  - Paket muncul acak di map (model Crazy Taxi); minimal 1 paket dekat pemain.
  - Visi, bukan MVP: main town dan region lain. Layout map rinci belum tertulis di GDD.
## **8. Art, Audio & UX**
*Tampilan, kamera, kontrol, dan feedback.*
  - Art direction: low poly kartunis, arah visual C (modern); identitas Yunani dibawa landmark dan ornamen.
  - Camera: isometric terkunci, full 3D.
  - Controls: 4 tombol drive + E untuk ambil dan antar.
  - Feedback: damage terlihat lewat 3 state mobil; angkanya baru muncul di laporan akhir hari. Penanda paket menunjukkan tipe, bayaran, dan arah tujuan.
  - Belum didefinisikan: audio dan layout HUD.
## **9. Technical Overview**
*Batasan platform, engine, dan jadwal.*
  - Platform: Mac, input keyboard.
  - Rendering: full 3D (sorting, collision, cahaya, dan physics native).
  - Jadwal: feature complete 25 Okt, checkpoint plan B 22 Okt.
  - Belum didefinisikan: engine, tooling, dan ukuran tim.

## **11. Open Questions & Risks**
Merangkum yang di dokumen ini sudah tertulis "belum ditentukan" atau "tunggu playtest", ditambah perapian pada versi ini.
  - Batas akhir malam setelah 20:00 belum ditentukan (bagian 10.1, Overtime). Diputuskan lewat playtest.
  - Angka quota, bayaran, dan biaya repair menunggu playtest (bagian 4.2, 4.4, dan 4.5). Catat tiap perubahan: nilai lama, nilai baru, alasan.
  - Hazard ketiga: perlu atau tidak, menunggu playtest.
  - Upgrade (bagian 4.5): angka kartu Bersih dan Gamble, peluang kartu Gamble, serta harga reroll dan kartu tambahan menunggu playtest.
  - Hadiah saat gagal quota belum ada: sekarang ulang total tanpa imbalan. Perlu diputuskan apakah ada imbalan kecil (rekor, unlock ringan).
  - Perapian di versi ini: "Run 3 hari" diubah menjadi 7 hari (bagian 5) dan denda 10% disamakan menjadi "per paket tak terantar" (bagian 10.1). Konfirmasi bila maksud aslinya berbeda.
  - Risiko: gagal quota berarti mengulang total tanpa imbalan; satu map harus cukup variatif untuk 7 hari.
  - Belum ada di dokumen: target audiens dan referensi game, anti-pillar, kriteria sukses playtest, tabel angka tuning.
