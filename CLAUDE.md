# Hermes Express GDD: notes for agents

- This repository holds the game's design; the Unity project (Hermes-Express) is a prototype that implements it.
- Follow the writing conventions in README.md: lower-case status words, `[TUNE]` for unconfirmed numbers, `D-0xx` decision references, every number named with its subject, formulas in code blocks.
- Edit specs in place and add a dated History line; never delete a decision, mark it superseded.
- Ask the owner about any design decision you would otherwise guess, in short batches of options with a recommendation first.
- After editing, run `npm run check` and `npm run build`; both must pass.
- Everything written in this repository is in English.
